# 双底示意图与现有策略核对

核对日期：2026-10-24。覆盖双底识别、方向确认、核心/小结构、支撑入场、风控、退出，以及冻结 v5.14 计划和交易记录。当前源码包含 v5.16。现有 245 项测试通过；未进行新全市场回测。测试通过表示符合已编码规则，不能替代与用户策略意图的一致性验证。

## 图与代码的对应

图表达两个低点、中间反弹形成颈线、上方压力/目标及下方结构失效线。图本身没有给出精确容差、确认天数、是否触线即成交或必须收盘突破，也没有要求必须在目标价全部卖出。这些不能直接从示意线推定。

当前实际交易链：日线双底收盘突破颈线 → 3–14 根方向观察期内完成回调恢复 → 核心 N → 较小 N → 支撑止跌确认 → 次日开盘 → 净盈亏比、距离及账户审核。双底是方向过滤器，实际订单属于后续 N 结构。

## 主要发现

1. **高优先级：双底确认与入场脱节。** `direction_double_bottom.py` 的候选池要求双底突破后额外回调恢复，再要求核心及小结构。v5.14 的“提前”只替代小结构的突破入场。601666 双底突破 2025-09-12，买入 2025-11-04；603663 突破 2026-01-27，买入 2026-02-26；001207 突破 2026-08-03，买入 2026-08-31；002262 突破 2026-07-01，买入 2026-08-31。不能把这些成交直接称为图示双底颈线附近买点。

2. **高优先级：三个不同失效概念需明确。** 双底候选底线是两底较低值；方向确认后 state.floor 改为突破后回调区间的低点，方向失效还包括顶部失败，且 floor 检查采用收盘价；交易止损来自更小 N 的 C 点，v5.16 又可移至其 K 线支撑区内部。更紧交易止损可以合理，但触发不等于整个 W 已失效。应分别保存 W 原始失效线、方向回调保护线、执行止损及所有者。

3. **高优先级：目标与入场结构不同。** 目标来自核心 N 的 C+(B-A)，再取有效历史压力上限；不是根据当前双底直接计算。图只写目标区/上方压力，无法据此要求固定双底等幅目标，但报告必须明确当前目标来自哪个结构。

4. **高优先级：盈亏比目标与实际卖出规则不统一。** target 用于入场风控，当前持仓按支撑、方向或调整超时退出，没有触及 target 即卖出的规则。此前 603663、001207 均曾在退出前触及入场目标。应明确 target 是空间估计还是可执行止盈，并单独检验退出变体；不能将预期 RR 当作实际兑现 RR。

5. **中优先级：时间尺度是同一日线的不同摆点灵敏度。** daily_nested 下方向、核心和较小结构都使用日线；较小结构不是实际小时线。因此无法据此证明盘中止跌或立即成交。日线次日开盘与 T+1 破位锁存是当前执行约定。

6. **中优先级：支撑区域是单根 C 点 K 线的 low 到 min(open,close)。** 不是两底共同测试的价格区域，也没有多个触碰点聚类。v5.16 的 max(原低点, 上沿-0.15 ATR) 是已知价格的启发式止损位置，未新增独立支撑确认。它还将 ATR14 和 0.15 写死；support_tighten 缺少严格布尔及适用模式校验，现有测试未专门覆盖该新参数的全部语义。应补充专用因果性、失效开盘与旧版本不变性检查。

7. **中优先级：计划生命周期会压低机会。** 非突破模式仅下一次开盘执行，失败不续挂；同 setup_id 在价格空间/账户审核前被标记 seen。这是一次性机会政策，不是双底定义；需要单独记录“结构仍在但本次订单失败”，再决定是否允许新的确认重试，不能静默重复旧信号。

## 已核对的合理部分

双底使用已确认摆点、低点差默认不超过 6%、颈线为两底之间最高 high；候选排除夹有更低底及其后已跌破底线的结构，并使用首次收盘突破及可观察日期，避免倒填订单。现有测试覆盖若干缓存等价、结构所有权、复权、支撑和 T+1 情形。没有证据据此宣布所有代码无前视，亦未发现可以解释全部稀少交易的单一计算错误。

## 建议的下一实验设计

先明确交易结构身份：同一个 W 的左底、右底、颈线、确认时点、原始失效线与压力区应贯穿记录。分别定义右底预确认试仓、颈线确认入场、颈线回踩入场，不把三者串成强制过滤链。原多层 N 策略保留作为对照。用示意图式合成行情覆盖：未破颈线、突破后无回踩、正常回踩、假突破、跌破原始底、执行止损触发但 W 仍有效。参数与执行约定固定后再做新版本同范围回测。

本次为检查报告，没有擅自将现有策略整体改成新的双底交易定义。
