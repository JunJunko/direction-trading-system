# 附件驱动的退出算法研究（2026-10-26）

结论：实现并验证三个候选，均未改善固定入场样本的总收益，不切换默认策略。回吐保护改善部分指标，但不足以成为已验证的优化版。

## 原书与算法的对应关系

附件《持续盈利：交易系统构建的思想与方法》，PDF共420页、无文本层。本次人工查看目录及PDF第310—321页，对应书页294—305，重点为295、302—305页；并非声称已阅读全文。

- 书页295：明确上级方向、核心交易周期、下级节奏；以核心周期波谷持续上移离场位。没有新波谷时还要判断调整相对之前调整的规模，利润丰厚时可容忍一定同级别横向调整，明显衰竭可提高敏感度。
- 书页302—303：空头实例在再次跌破反弹低点后才下移止损。做多镜像是回调完成并重新突破前高后上移保护。不能把未经确认的小波动直接当作新核心波谷。
- 书页304—305：达到目标不必立刻退出；示例利润丰厚后，将保护位设在成本至行情低点幅度的50%附近。做多镜像可研究限制回吐，但并非对所有持仓统一使用50%。
- 本次的左右各2根日K、严格收盘突破、2R启动阈值和最高收盘口径，均为工程假设，不能归为原书明确参数。书中的周期与同级别判断尚未被这些简化模型完整表达。

## 已实现的实验规则

E3/E4：保留v7压力转支撑和周线保护，叠加日线已确认波谷。仅处理入场后形成的点，左右各2根连续交易日确认，歧义外包K排除；E4还要求收盘超过波谷之前的已确认日线高点。候选波谷若先被收盘跌破则作废。保护只升不降。

E5：保留v7保护。冻结经济价格 E=入场价×入场复权因子，r=初始含成本风险金额÷初始股数×入场复权因子；维护自入场以来最高收盘经济价格 H。当 H−E≥2r，新增保护候选 E+0.5×(H−E)。最终保护取原保护与新候选较高值。这里保护的是价格涨幅，不保证扣费净利润保留50%，也不保证跳空后成交在保护价。

共同时序：先执行已有订单及原始止损；收盘检查此前生效的保护，失守发出下一可执行开盘退出；否则才更新保护，下个交易日生效。绝不利用当天最高价更新保护后再倒推当天最低价成交。复权使用经济价格，R不随保护位上移而重算。

## 研究边界及后续方向

这是固定入场的退出归因实验，不是取消2%限制后的新全量回测，也不是提前卖出释放资金后的重新选股组合。原双底2%入场限制保留。未平仓按市值估值，未扣未来退出费。既有日线OHLC、初始止损优先及合成复权股数约定沿用。成本压力测试冻结买入成交价格，仅改变佣金率和卖出滑点，税率及最低佣金固定。

前两种方案先冻结测试；看到结果后另立E5研究，属于同一已知开发样本上的后续假设，不能视为独立验证。没有网格搜索或以已知结果反复选择阈值。不能因为此次失败推断所有日线退出或所有利润保护方法无效。

后续应优先完善“核心周期/同级别调整”的客观定义，并把未启动即止损与盈利后回吐分开处理。结构退出可研究：固定核心周期→确认本次趋势的主回调→趋势恢复后上移对应支撑→核心结构破坏退出；在同级别识别通过因果性和跨样本验证前，不把任意小波谷当作主回调。

双底初始止损过近、止损后的重新入场属于另外的入场/风险实验。不得通过放宽亏损中的既有止损来伪装卖出优化。取消2%限制也需独立对照，否则无法辨别改善来自入场还是退出。
