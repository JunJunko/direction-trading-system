## 状态机

```text
寻找上级周期双底
 → 完整周线收盘突破颈线（确认的波谷已可见）
 → 等待日线反抽
 → 反抽触及颈线邻域且收盘未失守
 → 后续阳线收盘超过反抽阶段此前最高价
 → 输出次日入场意图
 → 触发后重新计算实际成交价下的扣费 RR 与风险数量
 → 确认新日线波谷后只上移离场价
 → 触及离场价后按可成交条件退出
```

第一轮未突破、缺少合格反抽、不出现重启、超期、跌破失效边界都会等待或取消，不强制交易。一个双底设置只提交一次入场意图，拒绝后不重复追单。

设 E 为含预计滑点的入场价，S 为反抽阶段（包含重启日）最低点乘 0.995，T 为独立高度目标。按候选数量扣除开仓、目标卖出和止损卖出的估计成本后，要求净收益 / 净损失 > 3。数量同时受单笔预算、组合风险、单股仓位、总仓位、持仓数量、现金约束。

目标只用于入场筛选，持仓不因抵达目标自动止盈。趋势波谷确认有延迟，允许回吐；初始预算不是最坏情况损失上限。

## 未完成的书中技术

没有完整“亲人图形”评分、斐波那契时间匹配、下一级小时结构、顶底全部演变、调整级别扩大退出、双背离离场及持仓周期升级。因此这是一条贴合主要逻辑的最小研究策略，不能称为完整复刻方向交易体系。

## 调整方式

调整参数创建新实验配置，保留旧配置与运行结果。若调整信号逻辑，升级策略 ID 与文档。不能为了让固定样本成交而压低 RR 或扩大目标。与基准对比信号数量、拒绝原因、真实 R 分布、回撤、交易费用、收益来源和不同阶段表现。
