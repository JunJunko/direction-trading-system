# 双底方向交易 v5.1 修复

v3 与原全量快照保持为基准，不覆盖原交易、参数和结果。修复版配置为 `configs/experiments/double_bottom_v5.json`，策略类型 `direction_double_bottom`、ID `double_bottom_v5_1`。原 v3/v4 参数不能用于此策略类型。

## 规则与修复

周线双底只是方向候选：要求前置下降结构、形态/中继面积比较、趋势时间匹配和右侧量能；突破后必须有独立的周线调整与重新上行确认，不能用突破之后经过三天替代实际反抽。确认后的多头方向持续有效，直到周线底线失守或确认顶部结构。方向不会随一笔计划未成交、净盈亏比不足或到期而删除。

在有效方向下寻找日线低—高—低 N 字，检查调整时间、幅度与速度相对趋势段的关系。空间由该日线趋势段与中继低点计算 `中继低点 + 前趋势段幅度`；先前确认的更近阻力位会限制目标。双底高度不再充当所有日线交易的目标。核心中继低点C被后续价格跌破，或对称量度空间已在历史上实现时，该N字不再有效；小节奏点低点被破坏也不能重启旧节奏。不能从旧历史中反复找一个尚未跌破A点的N字来填充当前计划。

生产配置采用周—日—小时：小时小 N 必须在核心中继之后出现、规模小于核心中继、调整与自身趋势匹配，确认恢复上行后形成候选。止损来自这个节奏点失败的位置，不能人为缩紧止损凑盈亏比。小时数据必须覆盖核心回调后完整的日内四段，缺失则等待数据，不能从日线拼造小时行情。核心周期 N 字与节奏点的数值定义仍属研究约定，不等同于书中所有人工形态判断。

候选在进入计划前接受净盈亏比严格大于3及共享账户风险审核；次日执行时再次审核实际价格、阶段策略、股票资格、预算和可成交性。成本、止损、仓位上限不放松。

一笔条件计划最多有效5个市场交易日，每日收盘复核并重新提交次日订单，保留原价格而非不断追高。节奏点失败、目标空间耗尽、方向失效或期限结束均取消计划；停牌不延长期限。同一节奏点不无限重复生成新计划，但同一方向下后续不同 N 字可独立生成新计划。每个实际执行日仍检查非ST资格。

持仓仍由所属策略管理：确认波谷上移离场位、方向失效、核心顶部或调整扩张产生退出计划；停牌与跌停时继续等待可成交条件，不虚构退出。此修复不添加自动分批止盈。

## 人工阶段策略

用户已选择人工提供带日期的阶段判断，程序不通过指标冒充人工判断。生产配置中的 `account_policy.stages` 目前为空，缺失/过期阶段禁止开仓。每条阶段记录需要 id、known_at、effective_from、expires、market_state、system_matched、gross_limit、reason；known_at 必须早于 effective_from。扩张、周期升级、同级别进场另外需要显式授权字段。不能把回测后编写的看多记录作为历史上已知策略来声称完整盈利验证。

生产运行示例（阶段记录已填入配置、小时文件已准备时）：

```powershell
python run.py csv --config configs/experiments/double_bottom_v5.json --csv <快照>/bars.csv --calendar <快照>/calendar.json --universe <快照>/universe.json --lower-csv <小时行情.csv> --evaluation-start 20251008 --evaluation-end 20261007
```

## 同一行情的结构实验

`configs/experiments/double_bottom_v5_structure.json` 明确声明 `research_scope=structure_only`，保留原v3固定资金限制，使用 `daily_nested` 的较小日线结构，评估修复代码在既有日线快照上的行为；它不声称拥有小时数据或人工阶段策略。省略研究声明且未配置人工阶段的方向策略会直接报错，不能静默放行。

```powershell
python scripts/replay_mainboard.py runs/20261007-212241-mainboard-v3 configs/experiments/double_bottom_v5_structure.json
```

研究输出单独保存数据来源、相同日线/股票池、策略配置、源码哈希、计划批准/拒绝/续期/失效事件、订单与净值。只用于诊断，不能据此选择更容易成交的定义或替代正式三周期验证。默认CLI仍指向v3基准，使用修复版须显式指定v5配置；保留基准不是继续宣称v3符合原书。

## 验证重点

原有方向确认、N字测量、缺失阶段、风险收缩、结构退出及截断历史一致性测试继续执行。新增覆盖：未成交计划原价续期；期限只取消机会；止损破坏不续期；复权因子变化同步调整重试价格；同一方向后续不同N字仍能入场；停牌不延长市场交易日期限；生产缺失阶段不得绕过。

书中依据：第一部分1983—1985行的顶底方向/中继交易分工；第二部分985行的趋势段量度，1289—1299行的时间架构、节奏点、盈亏比及结构离场。

首轮v5日线结构实验发现65个初始候选中47个复用了已失效或量度已完成的旧N字，因此在v5.1补充失效检查后重新运行。中间实验目录保留，不能作为最终修复版结果。最终回归测试共55项，含历史空间不可复用与核心C低点失效。

## 最终同一日线快照结果

v5.1结构实验目录：`runs/20261007-220914-mainboard-double_bottom_v5_1-structure`。20个初始候选、1笔买入及平仓，期末空仓；收益-0.5058%，最大回撤0.8339%。55项单元测试通过，逐项复核了原数据SHA256、资金账、交易日数、历史非ST资格、净RR及核心C未破/量度未完成条件。结果没有显示收益改善，且缺少人工阶段与真实小时历史，不能宣称完整交易系统已获盈利验证。
