# 头肩底 v1：颈线突破结构策略

> 2026-10-25 图形审查发现包络形态漏检及几何约束不足。以下为已回测 v1 的实现记录，候选数量不能视为标准头肩底数量；详见 [截图算法审查](inverse-head-shoulders-diagram-audit.md)。

识别修正版已另建为 [v2 包络策略](inverse-head-shoulders-v2.md)。

策略类型 `inverse_head_shoulders`，独立 ID `inverse_head_shoulders_v1`。
配置：`configs/experiments/inverse_head_shoulders_v1_structure.json`。

## 假设与规则

按用户提供的头肩底截图，将双底的“一套形态拥有入场、止损和目标”扩展为三个低点。
预期增加头肩底反转候选；代价是确认延迟、形态筛选误差，以及宽止损导致的低盈亏比。未宣称收益改善。

- 沿用双底的已确认波段算法，默认左、右各 2 根日线确认，不能将确认时间回填到低点日。
- 连续波段顺序为左肩、反弹高点、头部、反弹高点、右肩。头部严格低于两肩；两肩价差默认不超过左肩价格的 6%。
- 两个反弹高点价差默认不超过第一个高点的 3%，并都高于两肩。水平颈线取二者较高值；首版不拟合倾斜颈线。
- 左肩之前必须存在高于颈线的已确认高点，作为进入形态前下跌的最低结构要求；不额外声称满足完整长期下降趋势。
- 右肩之后首次收盘突破颈线触发。若右肩尚未确认，等确认后才能发出信号，且届时仍须收在颈线上方。
- 头部之后触及或跌破头部低点即失效；突破后已触及量度目标的形态不追入。
- 入场为信号后的下一交易日开盘，由公共引擎检查资格、成交条件、费用及账户风险。同一形态只消费一次；同时出现多个候选，按形态面积、右肩时间确定性选择。
- 初始止损为头部低点，沿用双底触及结构止损的处理。目标为 `颈线 + (颈线 - 头部低点)`；收盘达到目标后提交次日开盘退出，盘中触及目标不单独止盈。
- 不移动结构止损或目标，复权时同比例换算；保留持仓归属，退出仅作用于自己的持仓。

## 风控与哲学边界

继承 direct W 配置：单笔风险 0.5%、组合风险 2%、单股 10%、总仓位 50%、最多 5 仓，扣费后净 RR 严格大于 3。
截图中的“颈线附近买入 + 头部止损 + 一倍形态高度目标”毛 RR 约为 1，所以标准突破通常会被风控拒绝。这是预期行为，不能通过提高目标或放宽门槛制造成交。次日跳空后的实际价格仍由引擎重新评估。

本策略是独立日线结构研究候选，不替换原双底基准。固定量度目标退出沿用 direct W 实验语义，与哲学 v1 的“不设固定目标止盈”存在差异；该差异是此次按截图实现的明确实验边界，不代表更新哲学基准，也不代表完成三周期或跨环境验证。
