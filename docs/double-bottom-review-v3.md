# 双底识别完整性审查：v3

结论：当前仍是量化研究原型，未完整复刻书中的结构形态分析。v2 已修复任意跨波谷拼接，但边界测试发现仍有漏识别与状态处理问题。已有测试通过不等于所有边界正确。

## 复现与修复

| 问题 | 原实现后果 | v3 处理 |
|---|---|---|
| 第二底确认期间提前突破 | 右侧确认尚未完成时不能识别；完成后又因之前突破被排除，永远漏掉 | 区分实际突破观察日、第二底确认日与可行动识别日；确认后识别，禁止回填交易 |
| 相邻相等低价 | 严格 `<` 要求让平底全部消失 | 连续等低价合并为单个平底，以最后一根为代表，平底结束后等待右侧确认 |
| 周末最后交易日股票停牌 | 已完成周内有行情，却丢掉整根周线，影响波谷间隔与颈线 | 按市场日历判断周完成；有观察日期越过周末时保留本周最后有效价格，不虚构成交量；资产复牌后才有日线回调 |
| 突破后盘中击穿原底部、收盘恢复 | 仅检查颈线收盘，可能继续使用已经破坏的原设置 | 原底部盘中失守即取消，单独记录 bottom_broken |
| 反抽邻域只限制上边界 | 大幅下探、收盘拉回也被当作 2.5% 邻域反抽 | 低点必须在颈线上下容差内，且收盘站在颈线上；过深针形反抽暂不纳入此策略 |
| 最少历史长度多一根 | 最早有效结构被推迟；可能和突破过滤叠加漏信号 | 改为 left + min_separation + right + 1 |
| 无效参数缺少校验 | 两底相邻导致空颈线窗口、非整数确认周期崩溃、拼错参数悄悄生效 | 拒绝未知键、无效比例、无效整数及不合理边界 |
| 同一收盘重复调用 | 设置计龄和复权缩放可重复发生 | 收盘处理幂等，设置保存自己的价格因子，拒绝时间倒退 |

新增边界测试中，突破确认、平底、停牌周线和参数校验在修复前明确失败；其余状态和长度测试一并纳入回归。共 21 项测试通过，包括前缀一致性、完整盈亏交易、订单原因和组合风控。

这些修复仍包含明确的研究定义：严格相邻双底、平底代表点、盘中新低失效、颈线邻域宽度都不是宣称所有市场形态都必须如此。需要支持复合底、宽幅反抽时，应添加独立规则和版本。

## 仍不完整的部分

1. 前置下跌只用“此前最高价到第一底跌幅”筛选，未验证完整下降趋势、下跌级别和内部结构。横盘中的 W 可能也满足。
2. 两底匹配只有价格容差、间隔和形态深度，未实现书中时空面积比较、趋势与形态比例、“重神不重形”和量能质量。
3. 当前选择周线双底突破、日线反抽确认，是简化周期方案，不等于完整周线反抽确认与小时节奏点。
4. 重新启动用“收盘突破反抽期间高点 + 阳线实体”近似；未覆盖书中各类节奏点和运动方式变化。
5. 严格相邻波谷会遗漏复合双底；当前没有小级别波动合并为大级别结构的规则。
6. 目标仍用双底高度，尚未结合独立压力区域和趋势对称测量。退出仍缺顶部、调整级别扩大、背离和减仓。
7. 等待天数按该股票有行情的观察次数计数，未把全市场交易日与停牌期间计龄纳入策略接口；长期停牌研究需要扩展上下文。

因此不可称为“完整双底识别”，更不能把测试通过视为盈利验证。哲学门槛和资金风控保持原值，本轮没有为了成交而降低 RR。
