# v5.5 当前上涨段与及时结构保护

## 本轮假设

v5.4以入场时的旧调整长度筛选后续谷底，还要求重新突破调整峰值才保护，导致部分有效保护滞后。
本轮分离局部谷底确认、当前上涨段匹配、保护位生效三个环节。不新增固定止盈、浮盈百分比止损或减仓。

新建protection_mode=live_leg配置；entry_scale旧路径完整保留。自动账户、入场、费用和风险硬上限与v5.4一致。

## 动态结构的具体边界

1. 第一段使用已知节奏所在日线日期为活动锚点；小时节奏时间戳映射至所在日线日期，不把日线低点伪称为小时谷底。后续活动锚点取已接受核心保护谷底。
2. 当前上涨峰值只从活动锚点之后、候选谷底之前的已知K线生成，不引用后来价格。
3. 候选谷底仍需原left/right确认，默认左右各2根。其发生时间和保护决策时间分开记录。
4. 调整至少3根日线，持续时间不长于所属上涨段，幅度小于该上涨段，回落速率慢于上涨速率；谷底之后没有更低低点。
5. 观察到收盘高于谷底K线高点即可确认恢复，不要求收盘高于调整前峰值。
6. 新保护位为谷底乘原0.995缓冲，必须高于旧止损。决策在收盘形成，下一交易日才可用于成交。
7. 接受谷底后，活动上涨段从该谷底重新生成，原调整不继续通过恢复过程累积时长。
8. 等待期限为此前有效调整时长与当前上涨时长（至少3根）的较小值，再加原right确认预算；超期形成退出计划。

这些是可复现的工程结构定义，而非声称已完整还原书中所有主观级别判断。只有时间、幅度、速度匹配及恢复都满足，才将局部低点提升为保护结构。
保护日线顶部主要通过保护谷底跌破、调整超时和上级方向失效处理，保留自动账户收缩，不开放盈利扩张或持仓升级。

## 验证计划

81项单元测试通过。新增覆盖未创新高时保护、旧入场尺度不阻止当前调整、未来K线不可提前确认、谷底再破不升级、小时日期映射与止损单调性。
固定v5.3原10笔成交价与仓位，隔离退出规则；正式组合与v5.4比较，避免只选择表现有利的基准。
同一快照评估期实际为2025-10-09至2026-09-30。该数据已经用于研究，不是独立保留样本。
生产仍要求真实小时数据；daily_nested只作结构实验，缺失小时数据不得自动替换为研究模式。

## 回测结果与结论

主板非ST同一价格快照，评估2025-10-09至2026-09-30，初始资金100万元，费用和风险上限保持一致。

|版本|组合收益|最大回撤|买入/已平仓|
|---|---:|---:|---:|
|v5.3|+0.6420%|1.7920%|10/10|
|v5.4|-0.3135%|3.1597%|9/9|
|v5.5|+0.8463%|2.3986%|10/10|

v5.5胜率50%，利润因子1.432，无未平仓。81项单元测试通过；19项回放核验通过，包括因果时间、保护位单调性、结构归属、价格快照、费用、风险和运行源码一致性。

固定v5.3原10笔入场价和数量，退出净利润从6420.17元增至8596.15元（增加2175.98元）。这项比较排除了仓位变化的干扰，但不是独立样本验证。

改善并非普遍：603500第二笔从0.70R改善至2.64R；002895从2.82R降至1.64R，600066从1.55R降至1.07R。603500第二笔最高约4.55R，002895最高约4.64R，仍存在明显利润回吐。最高浮盈只是事后观测，不意味着可在最高价成交。

实际仅1次核心保护位上移：603500于2025-10-27从10.72610上移至11.75095，此时已经恢复超过原峰值。未创新高时上移的实际实例为0，虽然单元测试覆盖了这一可执行路径。收益改善主要来自动态调整期限，不能归因于早期利润保护已经奏效。

本轮是部分改善：收益超过v5.3，但回撤也更大；没有充分证据证明稳定践行小亏大赚。保留v5.5为实验候选，不修改默认配置，不继续用同10笔交易调参。后续须用未参与研究的区间和真实小时数据检验保护频率、亏损分布及大盈利保留能力。
