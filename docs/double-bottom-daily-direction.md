# v5.12：日线双底方向实验

## 变更假设（2026-10-22）

将 v5.11.2 的方向周期从周线改为日线，使双底、突破、反抽确认及方向失效按每根已收盘日K推进，验证能否更早提供方向。可能代价是结构存续更短、方向切换和交易候选增多；信号数量与收益变化需另行验证。保留原双底、反抽、确认因果性、净报酬风险比、费用和共享账户风险规则。

周期安排为**日线方向 → 日线核心波段 → 小级别入场**。真实数据配置要求小时行情，结构实验配置使用日线嵌套小结构代理。此次仅切换方向周期，未把核心波段整体迁移到小时线。

## 配置

- `configs/experiments/double_bottom_v5_12_daily_direction.json`：真实小时触发路径。
- `configs/experiments/double_bottom_v5_12_daily_direction_structure.json`：仅日线数据可运行的结构实验。
- 策略 ID：`double_bottom_v5_12_daily_direction`。
- `direction_cycle` 支持 `weekly` / `daily`，未指定时仍为 `weekly`。旧配置及命令行默认配置保留。
- `direction_retest_min=3`、`direction_retest_max=14`：反抽长度按所选方向周期的K线根数计数。日线模式为3至14根日K；具体起止及恢复条件仍由原反抽状态机计算。
- 旧 `weekly_retest_min/max` 参数继续兼容；未指定相应的新参数时，读取旧参数作为默认值。左右枢轴确认仍各需2根所选周期K线。

日线方向使用截至当前收盘的已知复权因子，不等待周末。日线右底直接使用该日日期作为核心波段起源边界；周线模式继续映射到所属周的实际日线低点。小时回调只消费此前已完成的日线父结构。

日线日志将方向阶段的 `weekly_*` 事件标为 `daily_*`，确认长度字段使用 `daily_retest_bars`，事件及入场依据附带 `direction_cycle=daily`。旧周线事件格式保留。

## 运行

使用已有行情和交易日历，将路径替换为对应文件：

```powershell
python run.py csv --csv <bars.csv> --calendar <calendar.json> --config configs/experiments/double_bottom_v5_12_daily_direction_structure.json
```

真实小时路径需使用不带 `_structure` 的配置并传入 `--lower-csv <hourly.csv>`。行情完整性和生产准入检查继续生效。

## 验证范围

新增测试覆盖：真实双底及反抽在周中确认、逐前缀一致性、重复回调、日线方向即时失效、右底日期归属、反抽长度单位、旧周线配置兼容、共享账户回放及小时数据门控。

同一历史快照的固定六股流程对照使用 `000001.SZ`、`600000.SH`、`600036.SH`、`002602.SZ`、`601226.SH`、`600458.SH`，评估区间2025-10-09至2026-09-30，之前数据只作预热。两组分别使用原 v5.11.2 周线配置与新增日线结构配置，各自运行共享账户、逐日上市及ST资格、相同费用和风控。样本事前固定，运行后不据结果调整参数；逐笔交易与拒绝原因随输出保存。

该对照用于检查实现及执行流程；样本此前已研究，不承担独立保留样本验证，也不支持将候选升级为基准。完整主板对照、独立时间留出验证及真实小时效果评估留待后续研究。

为完成日线全量扫描加入等价加速：复用已确认枢轴、复用收盘价后缀最大值、仅跳过不可能首次观察到突破的旧右底。新确认右底的延迟突破分支保留。冻结旧枚举器的逐前缀差分测试、平底及同根高低极值、复权重建和停牌周末复权缓存回归已覆盖，当前190项测试通过。日线缓存遇最新因子变化时已自动重建；另为周线缓存增加显式因子失效，避免停牌周的原始因子与当前归一化因子不同。运行归档保留启动时源码及测试日志。

本次日线版亏损及回撤较小，但仅有1笔成交，交易集合也不同，无法据此认定稳定改善。该区间已用于研究，缺少独立留出样本和真实小时线验证。
