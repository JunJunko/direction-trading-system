# 哲学底座 v1.0

本项目以《持续盈利：交易系统构建的思想与方法》为框架，目标是研究能持续执行的稳健交易过程。程序或一次回测不能保证盈利。

## 三观与可检查约束

| 三观 / 核心逻辑 | 系统约束 | 当前实现 |
|---|---|---|
| 世界观：走势有规律且存在不确定性 | 信号有失效位置；只用当时可见数据；不保证止损成交 | 延迟确认波谷、完整周线、结构止损、跳空与跌停处理 |
| 人生观：持续稳健盈利 | 优先约束损失和总暴露 | 单笔风险预算 0.5%、组合当前到止损风险预算 2%、单股 10%、总仓位 50%，均为研究初始值 |
| 价值观：评价是否按规则执行 | 记录计划、拒绝、成交和退出原因；区分执行质量与收益 | decisions/orders/trades 分开记录 |
| 小亏大赚 | 初始风险可承受；合理空间超过风险三倍；保留趋势利润 | 扣估计费用后严格 RR > 3、确认波谷跟踪止损，不设固定目标止盈 |

风险预算是计划约束，不是最大实际损失保证。跳空、跌停、停牌、组合相关性和日内未知顺序可使实际风险超出预算。持仓随市场上涨也可能超过初始仓位上限；v1 不自动强制再平衡。

## 变更边界

- 哲学与契约独立版本管理，不能借策略调参暗中修改。
- 策略只能提交意图；不能直接修改现金、仓位或绕过风控。
- 波谷与周线确认后才可使用，不将确认信号回填到极值日期。
- 原始价格单位下的止损只提高。复权引起的同比例重标价不是放宽经济风险。
- v1 不补亏损仓、不加仓、不临时提高持仓周期。
- 目标来自独立结构假设，不能用 E+3(E-S) 反过来制造“合理目标”。

这些约束体现框架方向，不能替代跨市场环境的长期验证。尤其 RR > 3 是书中此体系的具体筛选规则，并非所有盈利系统的普遍定律。
