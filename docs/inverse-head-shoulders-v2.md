# 头肩底 v2：包络搜索与形态高度归一化

策略类型：`enclosing_inverse_head_shoulders`。
策略 ID：`inverse_head_shoulders_v2_enclosing`。
配置：`configs/experiments/inverse_head_shoulders_v2_enclosing_structure.json`。

## 修正内容

v2 针对截图审查确认的三类问题修正识别，独立于旧版 v1 保存，便于复现与对照。

### 包络形态搜索

不再要求左肩、第一反弹高点、头部、第二反弹高点、右肩是相邻五个局部拐点。算法枚举已确认的左右肩组合，由区间实际极值确定中间的头部和两个反弹高点，保留大形态内部的小幅波动。

候选还必须满足以下约束，避免任选五点强行拼图：

- 头部是两肩之间的最低点，并且已经确认；两个颈线高点分别是左肩至头部、头部至右肩区间的最高点，且有已确认波峰依据。
- 左肩是前置高点之后至第一反弹高点之前的谷底，右肩是第二反弹高点之后至当前时刻的谷底，不能跳过更低的肩谷。
- 连续平底可作为一个头部；分离的等低点不能合并为一个头部，头部之后触及或跌破该低点也不通过。
- 使用所有原始区间高低点检查包络，未确认或日内顺序不明确的更深极值不能被忽略。
- 只在首次突破可被因果确认时发出信号；延迟确认时仍须站上颈线，并保留目标已耗尽、重复形态消费等限制。

前置高点的最低要求仍为高于颈线；在包络搜索中可越过内部小高点寻找这个原点。这不等于已完成长期下降趋势识别。持续时间对称性和完整前置趋势仍需后续研究，本次不声称修复了全部形态语义。

### 按形态高度衡量质量

定义 `D = N - H`，其中 `N` 是两个反弹高点中较高者，`H` 是头部低点。

| 参数 | 定义 | v2 默认值 |
|---|---|---:|
| `min_head_height` | `(min(左肩,右肩)-H) / D` 的下限 | 20% |
| `max_shoulder_height` | `abs(左肩-右肩) / D` 的上限 | 20% |
| `max_neckline_height` | `abs(高点1-高点2) / D` 的上限 | 10% |

这些是此次固定的初始研究定义，不是截图给出的数值，也未根据收益优化。与 v1 按股价百分比设置容差相比，这三个比例对价格整体同比例缩放或平移保持一致。v2 不接受旧参数 `shoulder_tolerance` / `neckline_tolerance`，避免静默混用单位。

确认窗口默认仍为左右各 2 根 K 线。水平颈线仍取两个反弹高点的较高值；本次未引入倾斜颈线拟合。

## 交易与风险

突破收盘确认后次日开盘执行；头部低点作为结构防守，目标为 `2N-H`。止损、退出、费用和账户风险约束沿用 v1，识别比例作为无量纲证据写入每个信号。

因此“突破入场、头部防守、一倍量度目标”与“净 RR 严格大于 3”的冲突仍存在。修正识别不意味着这些候选会通过风险门槛，不能将识别修复当作收益改善。

区间极值采用增量缓存；复权因子变化或历史回退时重建。测试将缓存查询与暴力逐区间计算比较，保证价格极值和首次突破日期一致。

## 验证结果

全套 **316 项测试通过**，其中新增 15 项针对 v2：

- 原审查中“内部锯齿导致漏检”的样例：v1 为 0 个信号，v2 恢复 1 个，三个大结构低点与预设位置相符。
- 近三重底、肩部差异过大、颈线高点差异过大的样例被拒绝；各项质量条件分别验证。
- 不能忽略更深的头部或肩谷；分离的等低头部被拒绝。
- 逐日前缀确认、重复信号、历史突破不重复使用、确认延迟、结构失效和空间耗尽检查通过。
- 价格缩放与平移、复权变化、区间查询、原交易引擎的净 RR 门控检查通过。

三个预先指定的真实回归案例已重新逐日运行。旧版信号被成功复现，新版在原信号日均排除了原布局：

按股票与左肩、头部、右肩日期匹配，两个版本共有 268 个布局，仅 v1 出现 1,865 个，仅 v2 出现 2,657 个；共有布局的信号日期没有变化。候选净增 792 个，不能直接解读为准确率提升：更广的包络搜索找回候选，质量约束同时剔除旧布局。

仅 v1 出现的布局中，1,754 个不满足至少一项 v2 几何阈值，另 111 个满足这些阈值但没有作为 v2 最终信号出现，还涉及包络约束与候选选择差异。这是分布诊断，不是误识别率或逐笔拒绝原因归因。

v2 全部信号的最小头部突出度为 20%、最大肩差 20%、最大颈线高点差 10%（浮点数尾差在容差范围内），三个既定真实问题布局在全量信号中均未再出现。

v2 的 2,925 个候选全部被拒绝：净 RR 未超过 3 有 2,740 个，信号日股票资格不符 156 个，风险预算不足以买入一手 29 个。已计算净 RR 最高 0.987858。零收益与零回撤来自全程空仓，不能评价策略收益能力。

全市场独立扫描与普通共享账户重算的全部信号 ID、日期、触发价、止损及目标一致。独立风险复核与账户拒绝计数完全一致，并核对了全部 241 行净值为 100 万元。相同行情、股票资格、窗口和账户规则由哈希及配置比对确认。

逐笔记录及核验：`plans.json`、`signals.csv`、`entry_audit.csv`、`comparison.json`、`account-verification.json`、`independent-risk-verification.json`。识别修正已通过本轮回归，但净 RR 契约冲突仍需作为独立的交易设计问题处理。
