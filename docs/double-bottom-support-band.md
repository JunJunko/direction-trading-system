# v5.15 支撑上沿回踩与窄防守带

假设：v5.14 使用整个回踩 K 线低点作止损。若原支撑区较厚，在已确认站稳上沿、再回踩上沿并收回后，可以用支撑上沿附近的窄防守带定义更早的交易失效。预期缩小初始价格风险，代价是增加扫损、减少可入场机会；不保证提高收益。

配置为 configs/experiments/double_bottom_v5_15_support_band_structure.json。沿用日线双底、同级核心及小 N 的原有归属要求，entry_mode 改为 support_band_retest。v5.14 仍保留。

## 事前固定规则

1. 原支撑区 [L,U] 仍为已确认小 N 回踩 C 点 K 线的最低价到实体下沿。
2. 在支撑首次确认当天，用截至该日的最近 14 根平均真实波幅 A（简单平均，包含跳空）固定缓冲。防守带为 [max(L,U−0.15×A),U]，带宽 / U 不超过 0.5%；过宽则放弃，不裁剪波动缓冲来强行通过。
3. 至少等到支撑确认后的另一个交易日。前一根完整 K 线最低价须高于 U，证明已在上沿上方交易；本次最低价进入防守带且未触及下沿，收盘重新站在 U 上方、收阳且高于前收，才确认本次回踩。
4. 原支撑下沿在 C 点后仍不得再次触及。价格离有效退出线过远时拒绝，不按目标价格反推或选择止损。
5. 下一交易日开盘执行，成交价到防守带下沿的距离不超过 1%，含费用净盈亏比仍须严格大于 3。跳空、历史股票资格、仓位、滑点等继续重新审核。一次失败不追单。
6. **防守带下沿是唯一的初始退出线和仓位风险计算基准。触及即触发全部退出，不等到原支撑下沿再卖。原支撑下沿仅为结构背景。** 受当日不可卖、封死跌停限制时保留触发状态，首次可卖时继续执行；不得删掉已经发生的开盘成交。
7. 后续只允许原有已确认更高核心低点上移保护线，不向下放宽。此时活动止损标记切换为 confirmed_core_floor；首次防守带记录仍保留作入场审计。

0.5% 指防守区域宽度，1% 指预计买入价到初始退出线的价格距离，两者都不是实际亏损保证；手续费、卖出滑点、跳空及成交限制可能扩大亏损。

例：原支撑区 9.50～10.00，支撑确认时平均真实波幅为 0.24，则防守带约为 9.964～10.00。先在10.00上方站稳，随后回踩至9.99并收回，下一日约10.05附近买入，初始止损约9.964。原9.50结构底未破，也须在9.964触发退出。示意数值不代表实盘成交承诺。

本版明确改变失效定义，不能沿用原68计划的71.43%目标先到率。因果性、未确认/未回踩拒绝、缓冲固定、复权、实际防守线风险审核、窄线触发退出、T+1延后、旧版本回归等均须验证；性能另以同一数据和账户对照。

## 验证状态

239 项测试通过，包括 14 项新增窄防守带测试。构造样例及冻结代码位于 runs/20261023-support-band-design，仅验证执行机制，不是历史收益回测；新规则收益和扫损率尚未验证。


该入口相对全量 v5.13 同时改变入场方式、上沿回踩确认、止损定义和距离上限，是整体规则对照，不应解读成仅抬高止损的单规则消融。v5.14 目前只有固定62股样本核验。

## 2026-10-24 固定规则全量实验

报告：runs/20261024-mainboard-support-band/report.html。

全部3,214只股票、2,856,672根日线已扫描，2023-01-03起因果预热，2025-10-09至2026-09-30考核241个交易日，100万元共享账户。冻结参数不做收益驱动调整。

结果为零入场计划、零成交、零持仓，期末100万元、收益0%、回撤0%；胜率、扫损及止损后5日反弹比例均无样本，不能解释为风险控制已改善。规则尚未进入盈亏比、1%入场距离或账户预算审核。

450次窄带判断观察中，宽度不合格（零宽或超过0.5%）180次、仍在首次支撑确认当日151次、没有回踩上沿95次、前一根未完全站稳17次、回踩后恢复条件不足4次、原支撑已触及2次、回踩确认期间窄带已触及1次。同一结构可能重复观察，这些不是450个独立计划。

同一62股范围单独对照：v5.14原止跌入场为4笔平仓、收益0.9899%、最大回撤1.6915%；v5.15仍为零计划与零交易。该表不能用于推断v5.14的全市场表现，也不能将其75%平仓胜率套用到新规则。

239项回归和6项报告检查通过；旧v5.13共享账户委托、交易、审核、每日净值与汇总精确复现；所有股票完成扫描，零计划结果与共享账户重算一致。当前结果只支持“这套日线组合条件在本区间没有提供入场机会”，尚不能评价窄止损的收益或扫损率。后续研究应区分带宽要求、额外回踩确认与周期分辨率的影响，不能把直接放宽参数后得到的收益当作独立验证。
