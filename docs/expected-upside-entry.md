# 入场预期涨幅门槛

2026-10-27 按用户要求，当前 v7 双底与头肩底配置启用 `risk.min_expected_upside = 0.05`。

买入必须同时满足：原结构目标价 / 预计实际买入价 − 1 严格大于 5%，以及原扣费后收益风险比严格大于 3。预计买入价包含买入滑点；5% 是目标价格空间，不是扣费净收益率，也不是达到目标的概率或保证收益。目标价不因门槛而上调，止损不因此收紧。

信号审核和实际开盘成交前均经 RiskManager 检查；若高开压缩空间，实际成交前重新拒绝。等于 5% 不通过。拒绝原因 `expected_upside_not_above_threshold`；审计保存 `expected_upside`、`min_expected_upside`。ATR 实验门槛没有一起启用。

当前配置：`configs/experiments/double_bottom_ihs_v7_pressure_support.json`。历史运行快照与旧版配置保留原口径；未指定该字段的历史配置不启用门槛。复现旧 v7 应读取原运行保存的 config.json。

验证脚本：`scripts/backtest_expected_upside5.py`。使用原 7,727 个信号，仅改变新增入场门槛；旧基准从历史快照读取。单元测试覆盖恰好 5%、低于/高于门槛、高开重新评估、原净盈亏比条件及非法配置。
