# 头肩底截图算法审查（2026-10-25）

## 结论

当前 v1 不能视为截图头肩底的完整实现。存在包络形态漏检、头部辨识度不足、肩部及颈线容差尺度失真，以及下降背景检查不足。同时，“突破入场＋头部止损＋一倍形态高度目标＋净 RR > 3”存在独立的数学冲突。

上一轮“零成交主要由盈亏比门槛引起”的账户诊断成立，但不能据此认为形态识别合格，也不能把“把止损拉近或改为回踩入场”直接当作截图算法的修复。截图明确把首次突破颈线标为入场触发。此前 2,133 个只是程序候选，不是经人工确认的 2,133 个标准头肩底。

本轮只审查，未修改策略源码、参数或回测记录。新增可复现审查脚本及可视化证据。

## 截图与实现逐项对照

| 截图信息 | 当前实现 | 审查判断 |
|---|---|---|
| 一个大形态，内部包含多个小锯齿 | `points[i:i+5]` 只接受相邻的五个局部拐点 | 关键漏检：大结构会被内部波动打断 |
| 头部明显低于两肩 | 仅要求头部严格小于两肩 | 极浅的新低也会被当成头部 |
| 左右肩处于近似高度 | 两肩价格差占左肩价格不超过 6% | 与形态自身高度脱节，浅形态中可能容忍极大不对称 |
| 两个反弹高点共同形成近水平颈线 | 高点差占第一个高点价格不超过 3%，取较高值为水平线 | 浅形态的两个高点可相差大半个形态高度，仍通过 |
| 底部反转之前存在下降走势 | 只检查左肩前最后一个高点高于颈线 | 证明了一次下跌，不能证明图示下降背景 |
| 突破颈线是入场触发 | 首次收盘突破、确认后次日开盘 | 方向符合；收盘、次日执行属于日线实现约定 |
| 目标高度等于头部至颈线的高度 | `target=2*neck-head` | 量度公式符合 |
| 红线表示整个结构失效，画在头部低点附近下方 | 精确头部低点作为交易止损，触及即退出 | 这是具体交易约定；截图没有给出缓冲宽度、触及/收盘标准 |
| 绿色目标区 / 上方压力，价格线仍继续上行 | 单点量度目标，收盘达到后全仓退出 | 图没有明确规定全仓止盈；代码也没有独立检测历史压力区 |

截图未给出 6%、3%、左右各 2 根日线或头部最小突出度等数值。不能将自定数值描述为图中的原始规则。

## 可复现问题

### P1：连续五个局部拐点搜索漏掉带内部波动的大形态

位置：`src/trading_system/strategies/inverse_head_shoulders.py:52`。

保留大结构“左肩 10、头部 8、右肩 10、两个反弹高点 13”，只在头部两侧添加不改变这些极值的小回撤：

- 简化干净走势：产生 1 个信号。
- 含内部锯齿的同一大结构：产生 0 个信号。

截图本身包含许多内部小波动，因此这不是可忽略的特殊情况。现有 direct W 使用 `hierarchy_double_bottom_candidates`，该函数明确保留包络底点，不要求所有局部拐点相邻；新增头肩底仅复用了底层 SwingCache，没有继承这部分搜索逻辑。

修复方向：在因果确认的波段层次中搜索包络的三底两峰，内部波动不能自动替换大结构的左右肩与头部；同时验证区间极值与层次归属，不能简单任选五个点强行连线。

### P1：形态相似度没有按形态尺度衡量

位置：`src/trading_system/strategies/inverse_head_shoulders.py:59`。

构造“肩部 10、头部 9.99”的近三重底，当前代码仍产生信号。另一个构造中，左肩约 100、头部 98、右肩 98.1，右肩几乎贴住头部，仍满足按股价计算的 6% 肩差条件。

全量 2,133 个既有候选的独立几何诊断：

| 指标 | 数量 |
|---|---:|
| 头部相对较低肩部的突出高度 < 形态高度 10% | 393 |
| 左右肩价差 > 形态高度 50% | 39 |
| 两个反弹高点价差 > 形态高度 25% | 344 |

形态高度为 `颈线－头部低点`。上述阈值仅用于展示分布偏差，不是经过验证的新规则；类别重叠，不能相加，也不等于误识别率。

已绘制的真实极端案例（仅用截至信号日的行情）：

- `600742.SH / 20260224`：头部相对较低肩部的突出高度只有形态高度的 **0.222%**；图中头部和右肩几乎同价。
- `603855.SH / 20260209`：左右肩价差达到形态高度的 **66.28%**；右肩明显更接近头部。
- `000537.SZ / 20260114`：两个反弹高点价差达到形态高度的 **55.88%**；当前画出的水平颈线无法同时贴近两个高点。

修复方向：用形态高度及波动尺度评估头部突出度、肩差、颈线差，并明确处理各段持续时间的悬殊差异。具体阈值需要事先定义并验证，不能按已有回测收益反向挑选。

### P2：下降背景的证据不足

位置：`src/trading_system/strategies/inverse_head_shoulders.py:68`。

在前期高点、低点持续抬高的构造走势之后，仅放置一个从高位回落的局部三底，算法仍接受。它可能属于上升趋势中的整理，不能直接称为截图所示的底部反转。

修复方向：明确前置下降结构及其级别、持续范围，与后续反转形态匹配；不把“存在一个更高的历史高点”视为完整下降趋势。

## 突破、失效、止损和目标的边界

首次收盘突破、确认延迟后仍须站上颈线、拒绝已经到达目标的追入，以及按当时因子复权，在本次审查范围内没有发现新的矛盾。但这些因果性检查通过，不代表形态定义正确。

`Intent(..., stop=head.price, target=2*neck-head)` 将结构失效位置绑定为每笔交易的初始止损。按这组定义，突破参考价 E>N 时：

`毛 RR = (2N-H-E)/(E-H) < 1`。

这与净 RR > 3 的冲突不会因提高识别精度而消失。若要严格保留图中的突破入场、头部级别防守和一倍量度目标，就必须承认当前账户契约不会接受这种计划。若另立局部止损、回踩入场或目标后继续持有的规则，属于新交易版本，不能称为直接还原截图。也不能仅为满足 RR 而人为缩小止损或提高目标。

建议顺序：先修正形态搜索及几何约束，用截图式构造和真实图审核验；然后单独明确图中未规定的执行与退出细节，最后再评估账户门槛是否兼容。
