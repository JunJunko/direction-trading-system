# v5.10 日线核心更新、节奏归属与有效压力

## 问题与假设

v5.9.1 枚举周线双底后，日线 N 筛选仍可能越过不合格的新调整，复用数月前的旧 N。小级别节奏仅通过日期下界与该旧 N 关联。目标又被任意旧日线高点压缩，不能区分小波动、已突破压力与当前波段的有效压力。

本轮不降低净报酬风险比 >3、不放大风险预算、不修改持仓退出。新增实验参数 core_mode=owned，旧模式与默认配置保留。预期修正波段归属和目标依据，成交数量和收益不保证增加。

## 可执行边界

1. 使用当日收盘已确认的日线波峰波谷（原左右确认参数，默认各2根）。最近一组低—高—低拥有当前核心；若这组不满足原有时间、幅度、速度、低点有效性及剩余投射空间条件，等待新结构，不回退到更旧的 N。新的低点尚未确认时不提前替换。
2. 核心上涨起点不得早于所属周线双底右底日期。右底是方向结构起源，方向确认日期仍是交易准入条件，二者职责不同。
3. 核心身份为 A/B/C 日期组合；记录 core_owner_changed。收盘发现核心变化或失效后，撤销尚未执行的旧入场机会。此前交易日已执行的订单不倒改，新核心不会直接改写既有持仓计划。
4. 小结构 A 必须在当前核心 C 当日或之后；保留小结构调整时间、面积、速度小于/匹配核心的条件，明确验证 A<B、A<C<B 的价格关系。记录小 A/B/C 日期、确认日期和 small_owner；入场使用独立 entry_core_owner，持仓仍保留原有 core_owner，不混用。
5. 压力只考虑核心 A 之前的已确认日线高点。其后必须存在已确认低点，低点不得晚于核心 A；对应下跌持续时间至少达到当前核心调整时间，下跌幅度至少达到当前核心调整幅度。否则它是更小的波动，不作为本级目标上限。
6. 高点之后若任何已知收盘突破该高点，该压力已被消费；不因为当前价格又在下方便自动恢复。突破后的支阻转换需要独立结构，本版不推测。
7. 目标仍取当前核心投射目标与有效压力的较小值；没有有效压力时使用核心投射目标，不能人为制造目标。记录每个压力的日期、价格、后续低点和保留/排除原因。

这些边界是书中时间架构、调整匹配、节奏止损及 >3:1 原则的量化约定，不是书中的逐字公式。尤其“最近确认的日线调整接替”和压力规模比较需要独立数据验证；固定左右枢轴不等于完整还原所有嵌套波段。更严格归属可能丢弃可以解释为较大波段中继的机会，当前选择放弃不明确的机会。

## 验证与适用范围

121项测试通过，包含新失败结构不得复活旧 N、方向起源日期、大小结构归属、压力规模/已突破失效、核心 A 边界压力保留，以及自动持仓归属字段不会破坏入场续期。测试还确认：新低点未确认时可以续期，确认后撤销旧计划。

全量比较使用同一3214只主板股票快照、信号及执行日非ST资格、100万元共享账户、原风险与费用。样本已经用于研究，不能当独立验证。daily_nested 是日线子结构代理，不是真实小时线；实际小时配置单独保留。

配置：configs/experiments/double_bottom_v5_10_structure.json（研究）及 double_bottom_v5_10.json（小时数据路径）。没有将候选规则晋升为生产默认。

## 全量结果及未通过的假设

v5.9.1 → v5.10：入场计划115→64，独立批准8→5，成交6→3，总收益+0.6315%→-0.1065%，最大回撤3.0079%→3.3323%。本轮121项单元测试通过；全部64个入场计划的日期和大小结构归属断言通过。但这只是归属记录与已定义规则的验证，不能证明最近枢轴就是正确日线核心。新规则没有改善样本收益，不能晋升默认。核心结构真正的嵌套分层、级别升级和父子波段关系仍需独立建模；不得把本轮简单接替规则声称为已经完整解决层级问题。
