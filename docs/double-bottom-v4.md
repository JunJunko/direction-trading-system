# 双底 v4：停牌识别与反抽状态修复

本轮修复两处可复现问题，不宣称完整实现原书形态体系。按策略变更流程，默认基准仍为 v3；候选配置为 `configs/experiments/double_bottom_v4.json`，策略 ID 为 `double_bottom_v4`，参数 `rule_version=v4`。省略该参数保留 v3 行为，以便同一代码下比较；旧 source 快照保持原样。

## 变更假设与定义

1. 停牌周的完整周线应在股票复牌后首次可见时参与识别。v3 的日线日期等于周线日期限制会跳过该周，下一周又被历史突破过滤永久排除。v4 按新可见的完整方向周期 K 线处理一次，用该 K 线收盘判断突破，事件日期仍为当前观察日。复牌日已经击穿底部或收盘失守颈线容差时不恢复旧设置。不回填停牌期间的交易。
2. 设置年龄不能代替反抽长度。v4 从突破识别后的首次收盘低于前一观察日收盘开始记录反抽，另行记录颈线邻域触及。重启之前必须已有至少 `retest_min_days` 个反抽观察日，重启日不计入；重启收盘必须超过整个反抽阶段最高价，阳线实体阈值保持原值。初始止损取完整反抽及重启日最低价，防止遗漏触及颈线之前的低点。

这仍是明确的研究定义：收盘回落只是回调起点近似，不是完整小 N 字识别；观察日只计股票有行情的日期，不是停牌期间的市场交易日。识别复牌日不回溯构造反抽，也不在该日直接提交入场意图。

预期改善：避免停牌漏识别与仅触及颈线就被当作反抽的误标。代价：入场可能推迟，结构止损可能更宽，净 RR 可能降低，交易可能被拒绝。不得因此降低 RR 或扩大目标。
