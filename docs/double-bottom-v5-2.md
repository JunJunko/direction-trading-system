# 双底结构修复 v5.2

## 变更假设

两张示意图强调同级别主要谷底和反抽确认，内部小波动不能替代整体结构。
旧版最近两个局部谷底、双底时间短于前期下降、右侧平均量强于左侧的组合限制缺乏充分依据。
横向反抽必须收盘突破整段最高上影，及小级别突破后再追日线高点，可能延误机会。

## 实现与界限

- 新建 v5.2 配置，structure_mode=hierarchy；legacy 路径和 v3 默认基准保留。
- 枚举已确认谷底组合，保留内部小波动，优先选择面积较大的整体 W。
- 两底仍要求价格差不超过原有 6%，内部不得出现更深第三底；此前必须存在高于颈线的下降起点。形态面积须大于该下降过程已辨认中继。
- 只接受右底以来第一次已知收盘突破，不复活旧突破；量能保留作证据，不再作为反转定义的否决条件。
- 删除双底总时间小于前期下降时间的否决条件。
- 反抽仍须守住结构和颈线，持续至少原有三周；斜向要求低点不下降且收盘超过前周高点；横向要求收盘区间守住颈线、低点不下降、收盘恢复并达到区间中点。整段宽度必须小于右底之后的上涨空间。
- 小级别调整确认后即可形成下一交易日计划，触发价取小级别前峰加原有缓冲，止损取小级别调整谷底。已收盘越过触发价不倒填成交。
- 未成交计划盘中已达到目标则失效；不再只看收盘是否达到目标。
- 盈亏比、成本、风险预算、仓位上限、ST历史过滤、T+1和保守成交判断不变。

这些数值定义仍是可检验的工程约定，不代表书中主观结构判断已被完整自动化。
现有 N 字空间及历史峰值压力上限保留，未同时放宽，避免把本次修复和目标空间假设混在一起。
结构枚举可能增加误识别；横向确认也可能在随后跌破，因此必须保留失效和止损机制。

## 验证

60 个单元测试通过，新增覆盖整体 W 内部小谷底、首次突破、横向反抽不必突破首根上影、未触发小级别计划和结构失效。
示意图测试使用构造价格，不是截图历史行情复原，也不证明盈利。
全主板对比使用 v5.1 的同一价格、日历和历史 ST 快照，区间实际为 2025-10-09 至 2026-09-30。
生产配置仍需人工提供带日期的阶段策略及真实小时数据；daily_nested 仅作结构研究，不能冒充完整三周期交易系统。
