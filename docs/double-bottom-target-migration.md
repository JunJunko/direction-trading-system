# 双底量度目标后的关键线迁移：研究 v0.1

本轮依据用户 2026-10-24 提供的开发规格实施。保留 QualifiedWRetest 的形态识别和入场，新增 target_migration_w 出场适配器。默认策略未切换。研究验收未通过：增益集中单笔，回撤上升，独立后段验证未完成。

## 接口与成交契约

- Bar：symbol/date/open/high/low/close/volume/factor/up_limit/down_limit。仅使用截至当前日的历史。
- Position：实际 entry/quantity/stop/initial_risk/entry_fee/setup_id/factor/plan。原始风险金额含预计止损滑点及双边费用。
- manage_position(history, position) 返回 ExitIntent 和事件，可上调 position.stop；当日收盘变更只能在随后交易时点生效。
- 原执行器先处理已持仓的盘中保护，再处理昨日待执行退出，再处理买单；买入当日跌破止损记录 T+1 延期，不取消真实买入。
- 原 v5.19 目标为收盘达到 T0 后次日开盘退出，没有盘中 T0 限价卖单。A0 保留该语义、成交理由和实际填价。A1/B 系列改成首次盘中触及后收盘决定，下一可成交日退出或继续观察。
- 保护止损跳空按原引擎实际开盘/日内低价约束填价，停牌、无量、一字跌停延期。涨停不单独触发止盈；也不能取消已执行保护或候选失败退出。

## 模块与固定参数

`src/trading_system/target_migration.py` 提供 TargetDecisionEngine、KeyLevelRegistry、ConfirmedSupportTrail 和状态/数据契约；`strategies/target_migration_w.py` 接入原系统。

研究参数随每个实验配置完整保存，默认 ATR 为前一日截止的 14 个 TR 算术平均，非 Wilder 平滑。首次触及当日收盘超过 T0 至少 0.35 ATR、阳线实体占比至少 0.55、收盘位置至少 0.75 才进入候选。连续两次收盘高于 T0+0.1 ATR 后接受；候选后第 3 根结束仍未接受则退出，低于 T0−0.25 ATR 提前失败。只使用路线 A，不混入回踩确认或单日接受。

确认波谷为左右各 2 根完整 K 线；同价平台使用连续平台末根作为 pivot，末根之后 2 根收盘确认。使用当时未跌破、持仓后形成且不低于已接受结构支撑的波谷。保护只允许提高到支撑−0.5 ATR，不下降、不增加数量。穿越 T0 或压力本身不会生成支撑。

压力来自已确认且未被收盘突破的历史高点；0.25 ATR 内高点聚类，以最早确认高点作代表。没有上方高点返回 None。该聚类阈值是明确的工程初始参数，非原书定量规则。B3 单独加入最高持仓收盘−3 ATR 风险线，单独事件记录，不能称为新结构支撑。

## 冻结入场与回归

运行：

```powershell
python -m unittest discover -s tests
python scripts/verify_target_migration.py runs/新的实验目录
python scripts/report_target_migration.py runs/新的实验目录
```

输出目录必须不存在，避免覆盖冻结结果。已核验输出：`runs/20261024-target-migration-verified`。最初机制运行保留在 `runs/20261024-target-migration-paired`，不是最终交付结果。

以原 v5.19 的 99 个冻结计划先精确复现共享账户；检查 orders/trades/entry_audit/equity 和 summary。再固定其中 14 笔实际入场的日期、价格、数量、初始止损、手续费和初始风险，逐笔复用旧成交引擎，聚合现金/权益。独立批次的 A0 退出日期、价格、数量、净利润、R、退出原因以及每日现金/权益均精确匹配旧结果。五臂入场签名一致。

固定入场实验不重新应用账户准入和自动仓位收缩，否则会改变入场集合，无法归因。后续同股票新信号可能与延长持仓批次重叠，因此属于研究批次模型，不能当成完成账户约束验证的实盘版本。账户原风险模块主要控制准入，不存在规格假设的自动超限强平，本轮没有新造该行为。
