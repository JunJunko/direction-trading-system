# v5.14 支撑附近止跌确认入场

变更假设：上轮 v5.13 在原小 N 高点突破价入场，68 个首次计划全部超过支撑下沿 2% 距离限制。提前到支撑附近的已完成止跌确认，可能降低买入价和初始风险，同时可能增加假反弹、止损和当日不可卖带来的损失。

本轮新增 entry_mode=support_rebound，原模式默认仍为 breakout。新配置为 configs/experiments/double_bottom_v5_14_support_rebound_structure.json，继承 v5.13 的日线方向、核心归属、已确认小 N 回踩支撑、2% 距离限制、净盈亏比严格大于 3、账户和持仓规则。

## 固定规则

1. 小 N 的回踩 C 点完成右侧确认后，取 C 点 K 线最低价到实体下沿为支撑区。保留原先小 N 的结构匹配和未知顺序拒绝条件。
2. C 点之后支撑下沿不能再次被触及。当日收盘价须高于开盘价，且高于前一日收盘价；收盘距支撑下沿不超过 2%，作为附近止跌确认。
3. 信号在该日收盘后才可见。用信号收盘价估算买入成本审核，符合距离和净盈亏比要求才提交下一交易日开盘买单。无需突破原小 N 前高；原突破价仅记录作对照。
4. 按下一交易日开盘价加买入滑点重新审核支撑距离、盈亏比、历史股票资格、涨停及账户风险。如果开盘已触及下沿或跳空超限，放弃。停牌或其他失败不续挂，不重复同一个 C 点的信号。
5. 开盘买入后，当天再触及支撑是真实发生的亏损风险，不能用日后最低价提前取消开盘成交。记录当日不可卖的触发，首次可卖时继续执行退出；保留跌停等成交限制。
6. 目标仍来自同一日线核心和当前有效压力，压力按实际计划价格评估。硬止损下沿和更高支撑确认后的上移逻辑沿用 v5.13。

执行中的 trigger 字段在本模式记录信号收盘参考价，entry_order=next_open 决定实际订单；传统模式继续使用高点突破条件。反弹信号价及原突破参考价随已知复权因子同步调整。

本轮是入场方式变更，尚未证明收益改善。日线确认只能在收盘后下次开盘执行；实际盘中更早确认需要真实更小周期数据。风险上限 2% 指价格距离，手续费、滑点、跳空、当日不可卖可能使实际亏损更大。

验证覆盖比原突破价更早的计划和成交、确认因果性、阳线与前收条件、支撑再次触及、远离支撑、次日开盘买入、跳空距离及失效、同日信号不可成交、当天触发后延迟退出、停牌不追单、复权基准一致，以及旧版本回归。

固定历史诊断样本采用上轮 68 个计划对应的全部 62 只股票，在看到 v5.14 结果前固定，按相同共享账户对照 v5.13。该范围不覆盖此前没有计划的股票，不能代替新策略全市场扫描或独立保留样本。

完整全市场扫描入口已支持本模式：

```powershell
python scripts/backtest_daily_direction.py --snapshot runs/20261022-mainboard-support-zone --config configs/experiments/double_bottom_v5_14_support_rebound_structure.json --experiment support_rebound --test-log runs/support-rebound-tests.log --output runs/20261023-mainboard-support-rebound
```

## 固定样本核验结果

201 项原测试与 12 项新测试合计 213 项通过。报告位于 runs/20261023-support-rebound-cohort-verified/report.md。

2025-10-09 至 2026-09-30 的固定 62 股共享账户中，原 v5.13 零成交；v5.14 生成 9 个首次计划，全部计划参考价低于各自原突破价，4 笔买入成交也低于原突破参考价。4 笔均已平仓，净利润 9,898.56 元、收益 0.9899%、最大回撤 1.6915%。3 笔盈利、1 笔亏损。

实际买入到初始支撑下沿的价格距离中位数为 1.3359%，最大 1.8022%。逐笔核验次日开盘加滑点成交、距离 <=2% 和净盈亏比 >3；另对 6 条含净盈亏比的审核独立复算全部费用。2 次执行因跳空后的支撑距离超限被拒绝，2 个计划因净盈亏比不足被拒绝，1 个首次计划因历史股票资格被拒绝。

002262.SZ 在 2026-08-31 开盘买入后，当天最低价触及支撑，成交并未被删除；按 T+1 保留退出状态，2026-09-01 可卖时退出。这验证本模式没有用日后低点回避已发生的开盘交易。

本次只证明入场机制及固定样本的行为变化。样本仅覆盖旧版产生过计划的 62 只股票，新版可能在其他股票产生更多信号，当前结果不能代替重新扫描全部 3,214 只股票，也不能证明未来盈利。
