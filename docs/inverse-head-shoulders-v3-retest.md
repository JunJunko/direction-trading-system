# 头肩底 v3：突破后回踩颈线确认

按用户新截图调整入场。v2 包络形态、头部突出度、肩部和颈线相对尺度保持原定义。新注册类型 `retest_inverse_head_shoulders`，实验配置 `configs/experiments/inverse_head_shoulders_v3_retest.json`。旧版本与已冻结报告不覆盖。

首次确认突破只登记形态，不产生买单。从形态已知日之后开始观察，最多等待 14 根股票日线。回踩低点需进入颈线上方 0.5% 以内；允许盘中轻微下穿，但最低价跌破颈线超过 2.5% 则取消该候选。回踩后收盘必须高于颈线、高于当日开盘且高于前一日收盘，才能确认；确认收盘最多高于颈线 2%。回踩与回升可在同一根已完成日线内出现，但不能使用最初突破日的低点冒充后续回踩。

确认后安排下一交易日开盘买入。若开盘低于颈线、触及初始止损，或计入滑点后的入场价超过颈线 2%，取消订单。停牌或无法成交沿用现有单日订单失效规则，不无限等待。交易日内后续是否失守只能事后观察，不能用来撤销已发生的开盘成交。

等待期间若头部、右肩失守，或盘中已达到目标，取消候选；超时也取消。取消或确认后不重新使用同一个形态身份。

初始交易止损沿用上一轮右肩最低价；头部保留为整体结构失效线。目标仍为颈线加头部至颈线的高度，首次收盘达到目标后下一可执行开盘退出。此次未启用 C1～C4。净盈亏比严格大于 3、费用、滑点、账户风险与 T+1 保持不变，不通过门槛的信号仍不成交。没有改用回踩低点止损。

数值窗口与容差是初始研究定义，截图只提供顺序和相对位置，没有给出这些数值。其中等待窗口与回踩容差参考已有双底回踩实现。回踩确认并不保证胜率改善。

复权全部使用当时已知因子。等待状态、持仓和待执行订单的颈线、右肩价、回踩低点、目标与入场上限同步缩放。测试覆盖首次突破不入场、回踩确认、失效/超时、禁止追高、等待及订单期间复权、逐日前缀一致、开盘下穿取消、正常成交与重复调用。全套结果保存于 `runs/ihs-v3-tests.log`。
