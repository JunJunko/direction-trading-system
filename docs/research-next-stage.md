# 下一阶段研究协议 v1（2026-10-22）

本协议在本轮新增行情读取和新实验结果计算前固定。历史版本、源码和结果均以哈希记录；研究输出进入独立目录。此轮不晋升策略，不以实验结果修改本协议阈值。任何修订另立版本并说明原因。

## 一、结构与保护审核

保留既有28个盲审案例，并从独立日线机会池按周线方向、区域、触发三项布尔条件分层、按固定哈希抽样。抽样不读取未来收益。图表截止观察日，采用当时可知复权尺度；审核页不包含未来行情、分组、成交结果与收益。先看无标记图，再可查看候选结构。旧案例曾被讨论，必须与新增案例区分，不能称全部从未见过。

审核字段：日线结构是否成立、级别/归属是否合理、观察时点是否有足够依据、保护位是否可上移；允许“不确定”。记录审核人、是否已见后续走势、备选日期和理由。没有独立审核输入时只报告机械一致性，不填写人工正确率。

保护实验固定原35个入场计划和原账户、退出时钟、成本。P0复现冻结基线；P1在原保护流程之后增加一个透明的对照：入场后已由左右各2根日K确认的谷底，确认后未被跌破，当前收盘恢复到谷底K线高点之上，且低点减原缓冲高于已有止损，可以上移；不要求它重新满足入场N的幅度、时间和速度匹配。原上级退出、超时退出仍优先。该对照是对多个保护门槛组合的诊断，并非原书分阶段保护的完整实现。日线确认当日收盘产生的新止损最早下一交易日执行。只在已经研究过的样本运行，不能以2笔成交证明优越。

## 二、优势来源

另建一个独立于周线W准入的机会池，而不是在仅有W的旧计划里寻找无W对照。每只历史主板合资格股票，在日线最新三个已确认枢轴首次形成低—高—低时，使用现有n_structure的几何、调整时间/速度及空间检查，仅检查这一组三点，禁止回退旧N；另要求C为B之后实际最低点且区间不存在同根高低点顺序歧义。左右确认各2根。每只股票20个市场交易日内只保留首个事件；规则在读取未来结果前应用。

每个事件记录三项当时可见条件：W=原周线双底及反抽方向仍有效；Z=收盘距截至前一日60根日K最高价不超过0.5ATR；T=当日收盘超过前一日最高价且当日低点不低于前日低点。Z仅代表这一种历史高点区域，不能外推到全部支撑阻力。此机会池不是v5.11.2原始交易算法的等价替换。

分别比较W、Z、T的有/无条件。每项比较精确匹配信号日期、交易所和另外两项布尔条件，再按20日收益、ATR/价格、20日平均成交额对数匹配，卡尺分别0.05、0.015、1.0。按固定事件哈希顺序贪心最近邻，不放回，不根据收益挑选配对。报告未匹配数量和配对前后平衡；匹配只能减少已观测混杂，不能证明因果。

主要终点：信号后第20个市场交易日的复权收盘变动/信号时固定ATR；5、10日为描述性副指标。另记录未来20日最大有利/不利变动。复权按事件尺度计算，未来因子仅用于事后收益核算，不进入信号。停牌缺少终点K线与观察期不足均标为缺失，不用未来首个交易日替代；匹配在计算终点之前完成，报告配对缺失及敏感性边界。

按信号月份对配对差值做固定种子1000次块自助法，显示探索性95%区间；另按标的聚类作敏感性检查。跨月份持仓与共同市场冲击仍可能相关。三个比较属于同一实验族，不据任何单个区间挑选策略。至少100个有效配对、30只股票、12个信号月份只是最低覆盖条件，不是统计功效保证。尚无独立重复及执行收益证据时不认定具有可交易优势。

本轮先回答信息增量。ATR终点、MFE/MAE不是成交收益；不把它们命名为净R、收益率或组合回撤。账户净R与回撤只在P0/P1真实执行模拟中报告。通过信息层后，才预注册完整交易规则与组合对照，避免同时改入场和退出。

## 三、独立数据验证

2023年起旧快照整体视为已暴露，其中2025-10-09至2026-09-30为开发评价区间；预热期不能重新命名为独立样本。先锁定协议与代码哈希，再尝试下载2026-10-01至2026-10-21新增日线、复权因子、涨跌停、逐日ST与日历，记录每个接口的成功/失败，拒绝缺失拼接。股票池重新获取L/D/P状态以发现新增上市标的；无足够历史的新标的明确排除并计数，不悄悄继承旧股票池。

新增短窗口仅作为冻结后首次读取的外部数据烟雾检查，不能代表独立长期有效性验证。即使接口成功，若20日终点未成熟、配对/月份不足，结果为“证据不足”，不输出胜出版本。原周线状态在旧期使用冻结事件带；新增期只能由完整历史按原周线算法因果重建，必须先在旧期核对方向事件一致性，否则停止新增期的W比较。

正式前瞻样本从不早于2026-10-23的首个实际交易日开始，固定规则持续记录全部机会，等待至少12个信号月份以及主要终点成熟。不得在结果出来后更改窗口、规则或排除失败事件；发生修订时旧前瞻期转为开发数据，新版本重新登记。不会通过重新切分旧样本宣称样本外成功。

## 决策

保留、调整或移除规则，依据独立审核、条件对照和独立数据三个证据层。程序测试通过只说明实现按定义运行；审核一致不说明盈利；信息差异不说明扣费可交易。实际报告逐项标明已完成、待独立标注、数据阻塞、未成熟，禁止统一写成“验证通过”。
