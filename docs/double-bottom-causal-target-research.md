# 独立 C0–C4 目标突破研究

本轮由用户于 2026-10-24 指定。保留正式策略与原数值参数；不调 ATR 倍数，不重写双底识别、入场或执行器。研究入口为 `CausalTargetW`，注册类型 `causal_target_w`，默认生产配置未变。

## 目标退出时序

原版 C0 在首次收盘达到 T0 后安排下一可执行时点卖出。普通盘中触及不会提前退出。

C1–C4 在同一个原版决策收盘，先用已经完成的当前 K 线及前日 ATR 检查候选证据，再决定是否产生目标卖单。只在这个窗口可以豁免；更晚的强势不能取消已排队或已成交订单。原来的首次盘中触及日仍记录，但不再是卖出或候选资格的唯一时点。数值门槛不变：0.35 ATR 超额、0.55 实体比、0.75 收盘位置；接受需连续两根收盘超过 T0+0.1 ATR；候选期限与失效规则不变。

因此本轮 603031.SH、603272.SH 都可以在后来首次满足原版目标退出条件的当天参加候选判定。它们不再沿用 A1 的过早退出；002451.SZ 仍在 2025-11-04 成为候选。该修正可能增加候选数量，是时序变更的直接结果，不是参数筛选。

## 实验职责

| 实验 | 目标豁免 | ATR 风险线 | 结构模块 |
|---|---|---|---|
| C0 | 无 | 无 | 原版 |
| C1 | 候选/接受规则 | 无 | 保留原止损，风险反例 |
| C2 | 同 C1 | 候选收盘计算，次日起生效 | 无 |
| C3 | 同 C1 | 无 | 接受后以确认波谷生成结构保护 |
| C4 | 同 C1 | 同 C2 | 同 C3，独立参与退出 |

ATR 风险线为持仓以来最高收盘−3 倍前日 ATR，单向上移。结构描述线取持仓后已确认且未被跌破的更高波谷；左右确认各 2 根 K 线。结构风险线为波谷−0.5 倍激活时前日 ATR，缓冲在该结构激活时冻结。ATR 收缩不生成新波谷，也不单独抬这条结构风险线。

实际执行保护为原始保护、ATR 风险线、结构风险线中的最高值。三者独立存储。只改变描述线不等于改变实际订单；结构线低于现行风险线时仍可记录结构证据，但不能降低止损。日志有形成日、确认日、检测日、最早可执行交易日、来源、价格和变更原因。退出归因另行保留旧引擎原因与当时生效的风险线来源。

## 三种研究模式

1. 固定入场配对：原 v5.19 实际 14 笔，入场价格/日期/数量/费用/初始风险相同。C0 精确回归旧订单、交易、审计与每日现金权益。此模式为出场归因，不重新控制账户准入。
2. 真实账户约束复验：原 99 个信号、62 只股票，通过原 Backtest 重新执行现金、仓位、风险准入和自动回撤收缩。数量和成交集合允许被这些旧规则改变。未向实盘提交订单，也不是全市场账户测试。
3. 扩展事件：全冻结快照 3,214 只股票，因历史 ST 资格只覆盖 2025-10-09 至 2026-09-30，全池可确认资格事件限于该区间。另按 SHA256(股票代码) 固定取 500 只，扫描 2024 至 2026-09 长历史，2023 预热；早期资格标记未知，不冒充可交易样本。固定观察 60 根可用日线的目标事件，候选后看 20 根日线。结构事件不等于持仓交易，重叠结构不等于独立样本；尾部不足单列。历史池不是新样本外。

扩展扫描使用工作进程内的前缀复权缓存减少重复运算，因子变化时完整重建。不会预先按未来复权因子修改历史。重点三只股票逐日复权 Bar 和识别器全部输出已与无缓存版本精确比较。

## 核心结果与反证

固定配对 C0/C1/C2/C3/C4 收益分别为 9.3996%、5.7158%、15.6576%、11.6189%、14.8922%；最大回撤分别为 0.7443%、13.2214%、3.5524%、6.9563%、3.5524%。

真实账户收益分别为 9.3996%、−0.3136%、11.6620%、5.3674%、11.0343%；实际成交为 14/4/11/6/11 笔。固定批次不能代替完整账户。

C4 相对 C2 的固定配对净利润减少 7,654.35 元，最大回撤不变；真实账户减少 6,276.76 元。成本压力复验仍落后。当前样本没有证明结构模块的额外收益或整体风险优势，不能据此继续堆指标。个别提前退出减少暴露时间，不等于提高净期望。

C2 改善开发样本净收益，但回撤显著高于原版，主要增益仍来自 002451.SZ。C3 在配对中改善、在账户中恶化。C1 在两种模式都恶化，保留宽止损会将原来的盈利交易拖成亏损。正式策略保持原版。
