# v5.3 持仓退出纠错实验

## 假设与范围

v5.2 的逐笔审计发现：603500两笔、600066在创新高后仍被旧峰至今累计时间、面积判成调整扩大；002895参考调整幅度变成负数，导致普通回落触发退出。
修正这些实现错误，并不保证每笔都赚得更多。延长持仓也可能增加利润回吐。

新建独立 v5.3 配置，入场 structure_mode=hierarchy 不变，新增 exit_mode=active_correction。
v5.2及v3基准保持原路径；默认仍为v3。

## 规则

- 当前调整从入场以来最近的实际最高价起算，不等待该峰成为已确认局部峰。
- 创出或重新触及最高价的当根K线不再把此前上涨累计成调整；之后未创新高的K线才形成新的调整。
- 调整幅度用峰值减去之后K线的最低价；不假定峰值当根K线的最低价发生在最高价之后。
- 完成调整的参照仍以已确认谷底为基础，但定位该谷底之前的真实峰值，时长、幅度和面积必须为正。无法构成有效峰谷调整的结构不更新参照。
- 无效旧参照不能触发调整扩大退出；结构止损、核心顶部及上级方向失效仍有效。
- 新模式日线、周线都使用一致的活动调整计算方式。止损不得降低。
- 保留原有有效调整的时间与面积、幅度扩大判定；不在本轮额外调整阈值或取消结构退出。
- 没有人工阶段授权，不自动升级持仓周期。不新增固定止盈或机械保本规则。

## 验证

67项测试通过，新增覆盖未确认新高重置、调整时钟重启、负参照不能强制退出、有效扩大仍退出、峰值当根低价顺序不确定、参照始终为正。
全量实验使用v5.2同一主板非ST价格、日历、历史ST快照，实际评估期2025-10-09至2026-09-30。

另有固定原10笔入场的独立持仓比较，隔离退出影响。这不是组合回测：不模拟资金再投资，使用原始日线，按正式引擎逐日调整因子、价格和股数；入场价格、初始风险和历史方向事件均来自原运行。
正式账户结果以全量回测为准。因持仓延长可能抑制同股后续入场，即使入场代码不变，组合成交数量也可能变化。

研究仍不含人工阶段策略，daily_nested不能冒充真实小时周期。该样本已经用于规则检查，不作为独立未见样本。

67项测试、14项结果核验通过。190个初始入场计划的日期、触发、止损、目标全部与旧版一致；10笔成交入场日期一致。固定入场诊断先验证旧版10笔退出日期完全复现，利润误差小于1分。

固定原仓位时，利润4847.20→4176.05元，减少671.15元。002895盈利1.71R→2.82R，但603500两笔分别2.08R→1.73R、1.40R→0.70R，600066为1.88R→1.55R。

正式账户利润6420.17元的提高，主要来自持仓延长改变后续仓位和风险预算，尤其000630股数15900→8900，亏损减少约2226.56元。新版平均盈利6954.64元，低于旧版7089.34元；平均亏损3566.40元，低于旧版3918.36元。不能将账户改善解释为整体利润放大。

明确错误已修复，但本次没有证明完整贯彻亏小赚大，也没有证明优于v3。利润回吐、同级别调整参照和真实小时节奏仍需独立验证；不根据这10笔继续反复调阈值。保持v3默认，v5.3为独立候选。
