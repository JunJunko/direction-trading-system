# v5.20 涨停持有及压力突破后的动态退出

原002451.SZ在2025-11-05开高低收均为8.57，与涨停价相同；旧目标收盘确认的次日退出在一字涨停开盘成交。新增独立dynamic_w_exit类型，入场保持v5.19。

当收盘突破当前压力，将其记录为已突破支撑；下一压力取当时已确认且未被后来收盘突破的更高摆点高价中最近一个。没有更高已知压力时，不虚构新目标，继续用入场后已确认、尚未再跌破的回调低点上移交易止损。收盘跌回最后突破压力之下，产生次日退出信号。

涨停收盘不发出止盈信号；次日开盘涨停时取消未执行的结构止盈，收盘重新评估。此规则只使用当时可知的价格，不能用当日后来封涨停的事实倒推取消早先的有效止损。原始及上移止损、T+1延后风险退出仍执行。压力字段随复权缩放。

验证采用v5.19冻结99个信号、同一62股的完整共享账户重放；不是只替换14笔旧交易的卖出价格，持仓延长、占资和自动账户收缩会改变后续买入。旧版委托、审核、交易及每日净值精确复现。保留原setup_id用于信号对照，strategy为v5.20。269项测试通过。
