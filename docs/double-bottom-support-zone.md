# v5.13 支撑区域实验

假设：v5.12 的确认入场经常距离回踩低点过远，使风险相对剩余上涨空间偏大。用已确认回踩 C 点的 K 线定义固定支撑区域，限制入场距离，并在触及下沿时退出，可能降低单笔风险；代价是减少入场机会、提高被短期波动扫出的概率。

本轮事前规则固定如下，不根据回测收益做参数搜索：

- 沿用日线双底方向、日线核心、日线嵌套小 N 的确认与首次突破入场。日线小 N 是小时结构的研究代理，未新增挂单抄底或真实小时数据。
- 支撑下沿 = 已确认小 N 的 C 点最低价；上沿 = 该 K 线开盘价、收盘价的较低值。无下影时允许退化为支撑线。支撑区域只是可检验的定义，不代表已经证明的买盘需求区域。
- 支撑只能在 C 点右侧确认已经完成后形成，入场前固定；后续复权按当时已知因子同步调整上下沿。
- 硬止损 = 支撑下沿，stop_buffer 从 0.005 改为 0。盘中最低价触及即触发；日线 OHLC 只能模拟触发，不能验证秒级成交。
- 预估成交价（含买入滑点）到下沿的距离 / 成交价 <= 2%。计划审核、续期审核和执行时均检查，跳空后超限拒绝；这是价格距离上限，费用、卖出滑点和跳空亏损仍另外存在。
- 含全部费用的净盈亏比仍须严格大于 3，账户风险、仓位、持仓管理和目标空间规则沿用 v5.12。持仓新支撑仅随已确认更高核心回踩上移，不下调止损。
- 触及后若受当日不可卖或封死跌停限制，保留退出状态，首次恢复可卖时按可执行开盘价卖出；价格反弹也不撤销已触发的退出。

配置：configs/experiments/double_bottom_v5_13_support_zone_structure.json。基准保留 v5.12，不自动替换。

验证包含支撑确认时点、2% 边界、跳空重新审核、触及后收盘收复、跳空越过止损、受限退出状态保留、当日不可卖、复权一致性、同根 K 线触发及失效的次序不明、新支撑确认后才上移。当前测试完成 201 项；回测启动时冻结日志为 199 项，两项补充测试另存 current-tests.log。

计划回测采用 v5.12 的同一冻结数据：3,214 只股票、2,856,672 根日线，2023-01-03 起预热，2025-10-09 至 2026-09-30 考核，100 万元共享账户。该区间已参与研究，属于样本内对照，没有新增独立保留样本。

## 本轮结果

全量结果位于 runs/20261022-mainboard-support-zone/report.html。候选零买入、零平仓、零持仓，期末权益 1,000,000 元、收益 0%、最大回撤 0%。原 v5.12 买入并平仓 1 笔，亏损 4,994.13 元、收益 -0.4994%、最大回撤 -0.6133%。零成交无法验证支撑止损的实盘收益或止损后的走势。

68 个首次结构计划与原版身份、日期、触发价、目标价完全一致。候选含买入滑点到下沿的距离最小为 2.3231%，中位数 6.0581%，全部超过 2%。其中 2 个计划受历史股票资格限制；其余 66 个独立计划（含续期共 86 次审核）均被距离限制拒绝。取消缓冲使首次计划的纯价格止损距离中位数从 6.4344% 降为 5.9642%，仍不能使现有突破买入靠近支撑。

stop_buffer 为现有共用参数，本轮设为零同时改变方向失效参考线、入场及持仓保护的缓冲，因此部分方向事件计数改变、续期从 27 降至 20；首次计划仍逐项相同。不能把本轮视作仅一个止损价参数的独立消融实验。

已验证原日线账户完整复现、全量扫描计划与共享账户重算一致、86 次距离审核独立复算、68 个支撑区域从原始行情及当时因子独立复核。该结果支持继续研究更早的支撑附近入场，尚不能证明支撑止损能提高收益。
